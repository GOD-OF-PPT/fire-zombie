# 棱镜蜂群：霓虹协议 · PRISM SWARM: Neon Protocol

竖屏 3D 跑酷射击 Web 游戏。你指挥一支「棱镜战士」小队冲过霓虹数据干线：**左右拖动选路，射击全自动**，穿过数字门让蜂群壮大，射击金框门把危险选项“打”成收益，击破能量舱进化武器，最后在区域尽头迎战首领。

> 主题选择过程见 [docs/THEME_SELECTION.md](docs/THEME_SELECTION.md)。

## 快速开始

需要 Node.js ≥ 22.12。

```bash
npm install
npm run dev        # 开发服务器 http://localhost:5173（加 --host 可用手机局域网访问）
npm run build      # 类型检查 + 生产构建 → dist/
npm run preview    # 预览生产构建
npm test           # 模拟层单元测试（Vitest）
npm run test:e2e   # 端到端流程测试（Playwright，会自动 build + preview）
```

`dist/` 是纯静态文件，可部署到任意静态托管。

## 玩法要点

- **数字门**：绿色 `+ ×` 增加战士，红色 `- ÷` 减少；一排门只能选一扇，人数始终为 0~999 的整数（乘除统一向下取整，见 `src/sim/math.ts`）。
- **金框门（可射击）**：子弹命中会逐步提升数值，充能条显示下一步进度；把 `-5` 打成 `+6` 会出现“负转正”演出。带锁的 `÷` 门破锁后翻转为 `×2`。
- **能量舱**：击破获得武器——折射散弹（扇形）、超导贯穿（穿透）、新星迫击（范围爆炸）、绝对零度（减速）、环轨刃（护卫刀刃 + 6 名战士）。同类重复获得升级至 Lv3。
- **电容桶**：射爆后范围爆炸并连锁，还会抬高附近金框门数值。
- **棱镜**：子弹穿过一分为二并增伤。
- **共鸣槽**：改善门 / 破舱 / 连锁爆炸充能，满后 6 秒超载（射速 ×1.5、穿透 +1）。
- **敌人**：狂暴刺球（基础集群）、烈焰迅龙（红色锁定线预警后高速冲锋）、重甲巨魔（持巨棒高耐久重装怪）、分裂史莱姆（击破后一分为二）、噬能骷髅灵（偷取前方门数值，击毁即刻返还）。敌人冲进蜂群会造成损失，人数归零即失败。
- **首领**：三个区域各有一名巨型首领（赤焰魔像王 / 双生魔龙 / 深渊魔王），地面红区填满前移动到安全车道；蜂群规模与武器直接决定输出。

### 长线目标（让每一局都有收获）

- **星级**：通关时剩余蜂群决定 1~3 星。
- **区域挑战**：每个区域 3 个一次性挑战（如“改善 4 扇金框门”“首领战损失 ≤ 10”），完成奖励晶核。
- **强化工坊**：每局结算获得晶核（失败也有），永久升级「先遣编队 / 超频弹芯 / 共鸣放大器」。
- 三个区域依次解锁，难度、敌人组合与首领机制各不相同。

## 美术与渲染管线

采用 **Q 版商业休闲卡通（Toon + 描边）** 3D 美术方案，所有角色与怪物均使用 **CC0 1.0 公共领域** 骨骼绑定动画模型（详见 [`public/models/ATTRIBUTION.md`](public/models/ATTRIBUTION.md)），经 `scripts/build-models.mjs` 裁剪冗余挂点、重调高饱和度卡通色板并打包为 `public/models/*.glb`（共 12 个模型，总计约 4.1 MB）：

- **三阶英雄编队（Quaternius Toon Shooter + Animated Mech Pack）**：
  - **蓝晶突击队员**（`hero_trooper.glb`）：Q 版大头比例战士，奔跑射击、待机与胜利挥手骨骼动画。
  - **黄金重装队长**（`hero_heavy.glb`）：队伍壮大至 14 人以上时编入指挥圈。
  - **重装突击机甲**（`hero_mech.glb`）：队伍壮大至 55 人以上时在侧后卫展开巨型双足机甲协同推进。
  - **5 把可实时切换的 Q 版 3D 武器**：挂载于右手骨骼节点（`Index1.R`），切换脉冲冲锋枪 / 折射双管霰弹 / 超导狙击轨炮 / 新星火箭筒 / 绝对零度榴弹发射器时全员手中的 3D 枪械同步更新；能量舱内亦旋转展示对应 3D 卡通武器核心。
- **五类高辨识度怪物（Quaternius Ultimate Monsters）**：
  - **狂暴刺球**（`enemy_crawler.glb`）、**烈焰迅龙**（`enemy_dasher.glb`，冲锋前伏身蓄力 `Duck` → 狂奔 `Run`）、**重甲巨魔**（`enemy_bastion.glb`，近身挥舞巨棒 `Weapon`）、**分裂史莱姆**（`enemy_mitosis.glb`）、**噬能骷髅灵**（`enemy_siphon.glb`）；击杀时触发骨骼倒地翻滚动画，冰冻命中呈现冰蓝着色与动作减速。
- **三大关底首领**：
  - **赤焰魔像王**（`boss_warden.glb`）：戴金冠的赤红石像鬼巨王，振翼盘旋与重拳轰击。
  - **双生魔龙**（`boss_hydra_a.glb` + `boss_hydra_b.glb`）：紫焰古龙与电光苍龙双龙同屏振翅，二阶段分体双核独立作战。
  - **深渊魔王**（`boss_omega.glb`）：执三叉戟的双翼深渊魔王，配合几何测地线力场护盾、星环与双护盾晶塔。
- **三阶卡通着色 + 屏幕空间描边 + 选择性辉光**：
  - [`src/render/models/toon.ts`](src/render/models/toon.ts)：抗锯齿三阶色带 `MeshToonMaterial` + 菲涅尔边缘光 + 平滑法线背面外扩屏幕空间等宽卡通黑描边（共享同一 `Skeleton` 骨骼矩阵，零额外蒙皮计算开销）。
  - 选择性 `UnrealBloomPass`（高阈值 `0.93`）：仅让高能弹幕、枪口火光与爆炸产生霓虹辉光，保持角色五官、描边与数字门文字锐利清晰。

## 项目结构

```
public/models/ 精简打包后的 12 个 CC0 骨骼动画 .glb 模型与版权说明
src/
  sim/         纯逻辑确定性模拟（1/60 s 固定步长、对象池、扫掠碰撞），不依赖 DOM/Three
  config/      武器、敌人、三个区域的手工编排关卡脚本与首领参数
  render/      Three.js 渲染：GLTF 模型池与骨骼动画状态机（gltfLibrary.ts）、卡通着色与描边（toon.ts）、门牌纹理与粒子特效
  ui/          DOM HUD、标题、工坊、暂停、结算
  audio/       WebAudio 程序化音效与分轨音乐（无外部音频文件）
  input/       触摸/鼠标相对拖动 + 键盘
  app/         游戏状态机、事件→演出映射、存档、元数据、自动驾驶
tests/unit/    模拟层单元测试（门运算、CCD、首领、平衡性自动通关等）
tests/e2e/     浏览器流程测试
scripts/       build-models.mjs（GLB 资产管线）与 shot.mjs（开发截图脚本）
```

### 调试 URL 参数

- `?play=1&sector=2`：跳过标题直接开始指定区域
- `?unlock=1`：解锁全部区域
- `?autoplay=1`：自动驾驶游玩（演示用）
- 控制台 `window.__prism.fastForward(秒, 是否自动驾驶)`：以固定步长快进当前局

## 技术说明

- 模拟与渲染分离：模拟以固定 1/60 s 步长推进，渲染帧率无关；暂停时累加器清空，不会出现计时/攻击/碰撞脱节。
- 高速子弹使用扫掠线段 vs AABB 检测，避免穿透漏判。
- 蜂群超过可见上限时按 1/5/25 分级压缩显示（≤48 个角色模型：战士 / 重装兵 / 棱镜机甲），真实数量与战力仍按整数结算。
- 所有门、奖励使用一次性触发标记，同排门互斥。
- 重开时释放所有对象池、清空计时器/特效/结算状态。
