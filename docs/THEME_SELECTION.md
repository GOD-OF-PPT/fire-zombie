# 主题与表现方向遴选报告 (Theme & Presentation Selection)

> 对应需求条款 (`ORIGINAL_REQUEST.md` L49–59, L109)：在进入代码实现前，提出四个明显不同的原创世界观与视觉表现方向，评估它们如何自然服务于“队伍扩张、火力成长、可射击数字门抉择与终点对决”的核心玩法，并论证最终选定方案——**《棱镜蜂群：霓虹协议》(PRISM SWARM: Neon Protocol)**。

---

## 1. 核心体验对主题与媒介的设计要求

竖屏数字门跑酷射击玩法的乐趣建立在**高速视觉预判与瞬时算术抉择**之上，理想主题与渲染方案必须同时满足五项核心诉求：

1. **世界观自洽性（Diegetic Fit）**：穿过 `+ / - / × / ÷` 数字门实现瞬间增殖或折损、提前射击数字门改写收益符号、击碎容器展开新式武器等机制，应当在世界观中自然成立，摆脱同质化的“蓝衣小人打红衣僵尸”模板。
2. **纵深预判视野（Horizon Foresight）**：玩家需要在“清理前方敌人、射击改善负值数字门、击破高耐久奖励核心”三者之间分配站位与火力，必须能提前 `3–4` 秒看清远端门排与障碍布局。
3. **竖屏高对比度与文字锐度（9:16 Clarity & Crisp Typography）**：阵营、危险、奖励与可交互目标必须在手机竖屏上一眼可辨；数字门文字在高速逼近与缩放时保持锐利，不被爆炸或震屏特效遮挡。
4. **规模感与真实战力兼顾（Crowd Scale & Authentic Power）**：从单机起步扩张至数百规模时，既要呈现编队进化与弹幕蜕变，又要在高同屏单位下稳定保持 60 FPS。
5. **终点对决分量感（Boss Showdown Impact）**：关底强敌需具备多阶段压迫感、清晰的预警空间以及与本局成长挂钩的爽快击破反馈。

## 2. 四个候选主题与表现方向提案

### 候选方向 A（最终选定）：《棱镜蜂群：霓虹协议》(PRISM SWARM: Neon Protocol)
- **世界观与阵营**：失控的行星级光学主干道（*Hyper-Bus*）。玩家操控电光青色折纸几何风的**棱镜拦截机蜂群（Prism Interceptors）**，迎战侵蚀总线的黑曜赤红**红移恶意构造体（Red-Shift Malware）**与防火墙巨像。
- **表现媒介**：**风格化真实 3D**（`Three.js` WebGL2 硬件实例化 `InstancedMesh` + 高分辨率 Mipmap `CanvasTexture` 数字门铭牌 + 局部叠加态光晕与跑道平面冲击环）。
- **如何服务核心玩法**：
  - **数字门与射击改写**：数字门即总线上的**光学逻辑门（Clone / Fork / Purge Gates）**；带琥珀金准星框的**可重写寄存器门（Mutable Register Gates）**在承受玩家数据包射击时会实时累加数值，将危险的 `-12` 或 `÷2` 逆转为绿色的 `+8` 或 `×2`。
  - **队伍扩张与分级合体**：蜂群保持 `0..999` 严格整数规模；视觉上通过 **3 阶实时编译晋升**（`1` 阶侦察棱镜 = `1`、`2` 阶先锋双翼 = `5`、`3` 阶主权巡洋舰 = `25`）在 `≤ 48` 个高精度 3D 实例内呈现饱满舰队层次，同时真实总 DPS 严格随完整整数规模线性增长。
  - **火力升级与特色机制**：击碎旋转六棱柱**超频秘钥舱（Overclock Vaults）**可展开散射、超导贯穿、等离子范围轰炸、零度凝滞等 5 类战术武器及护卫旋刃；独创**黄金折射增幅镜（Golden Prism Lens，`✦ 2× SPLIT`）+ 棱镜共鸣超载（Resonance Overdrive）**，只需横向走位借镜折光即可令单路火力翻倍破局。

### 候选方向 B：《符文锻阵：机关长城》(RUNE FORGE: Clockwork Rampart)
- **世界观与阵营**：云海之上的古代机关城垣栈道。青玉黄铜质感的**神机连弩傀儡**迎战墨铁兽面**墨煞攻城傀儡**与饕餮机关兽。
- **表现媒介**：**2.5D 分层矢量透视渲染（Canvas2D / 伪 3D）**，暖色石砖跑道配宣纸水墨与齿轮粒子。
- **如何服务核心玩法**：
  - 数字门化作**八卦衍兵阵门**，射击负向凶门如同以弩箭铭刻净煞符文、逆转吉凶；奖励箱为鲁班秘匣，解锁连珠弩、震天雷与寒铁箭。
  - **优势与局限**：东方机关美学辨识度高；但在狭窄的 `9:16` 竖屏上，40 余具带齿轮细节的人形机关傀儡容易产生轮廓噪点，且深色水墨爆炸与暖灰石面在高速运动中会削弱数字门白字的瞬时对比度。

### 候选方向 C：《微光免疫队：血管急行》(BIO-PULSE: Nanomedic Rush)
- **世界观与阵营**：生物发光的微观动脉腔道。珠光天蓝色的**纳米医疗潜航群**清除紫红色**变异病原体、分裂孢子**与超级菌株母体。
- **表现媒介**：**精致 2D 俯视软体着色器（2D + WebGL Organic Shader）**，带流体尾迹与弹性形变反馈。
- **如何服务核心玩法**：
  - `×2 / ×3` 数字门天然对应**细胞有丝分裂膜**，射击酸性负值门相当于注入碱性中和剂改善膜通透性；奖励靶为基因强化胶囊。
- **优势与局限**：增殖隐喻贴切；但血管内壁固有的粉红/暗红基调与“红色负向危险门、洋红敌人”色相接近，违反商业休闲手游“危险色零歧义分离”的清晰度原则，且软体碰撞缺乏硬朗干脆的弹道打击感。

### 候选方向 D：《星轨折纸舰队》(STAR-ORIGAMI: Paper Armada)
- **世界观与阵营**：铺满黄铜刻度的星图制图桌。象牙白与钴蓝折纸战机编队对抗墨渍锡箔掠夺机与碎纸机巨兽。
- **表现媒介**：**平涂硬边折纸 3D（Flat-Shaded Papercraft 3D）**，明亮浅色桌面背景配投影与折痕高光。
- **如何服务核心玩法**：
  - 数字门为**活字拓印框**，穿过即拓印出新纸飞机，射击门框可翻动计分牌字模；奖励靶为火漆补给盒。
- **优势与局限**：几何轮廓干净轻巧；但浅色纸面背景限制了高能发光弹幕的层次表现，黑墨爆炸在白字门牌后方容易造成局部明暗反转，关底对决的史诗压迫感偏轻。

## 4. 最终选择理由与整体贯通设计：《棱镜蜂群：霓虹协议》

综合对比，**方向 A《棱镜蜂群：霓虹协议》(PRISM SWARM: Neon Protocol)** 在玩法可读性、机制融合度、程序化 3D 表现力与运行性能上均取得最优解：

1. **真实 3D 透视 + 高清 `CanvasTexture` 门牌，兼得空间纵深与文字锐度**：
   - `46°` 俯仰 3D 追尾镜头（带 `15%` 阻尼横向视差，确保中轴分界线 `x = 0` 稳固不晃）让玩家能同时观察近处弹道、中距敌群与远处门排。
   - 摒弃会导致文字发虚的全屏泛光后处理（`UnrealBloomPass`），改用按需重绘的 `512×256` Mipmap `CanvasTexture` 高对比度胶囊门牌配合 `0.28` 透明度能量门帘——数字在高速移动与缩放中始终锐利如刀，门后敌情亦一目了然。
2. **严格的商业级语义色彩与剪影编码**：
   - **低明度哑光跑道**（第一关深海蓝 `#0B1021`、第二关超频靛 `#120B29`、第三关奇点黑曜 `#190814`）将全部视觉焦点留给交互对象。
   - **阵营与交互零歧义**：友军为向前锐角折纸青色棱镜（`#00F0FF`）；正向门为翠青色（`#00E6A8` + `▲`）；负向门为赤红配底部黄红斜纹警戒带（`#FF2E54` + `▼`）；**可射击改写门**镶嵌醒目的琥珀金靶框与充能刻度（`#FBBF24`），而**固定门**采用暗钢锁扣立柱（`#475569`）且允许子弹无损穿透打击门后目标；奖励秘钥舱为旋转金紫六棱水晶；连锁电容桶带地面 `r = 4.5` 虚线爆炸圈。
3. **有辨识度且零额外按键负担的原创微创新——“折射增幅镜 + 共鸣超载”**：
   - 跑道与 Boss 战场中缓缓横移的**黄金折射增幅镜（`✦ 2× SPLIT`）**可将穿过的友军弹幕一分为二并强化 `1.35×` 伤害（单路等效 `2.7×` 火力），鼓励玩家通过精妙横向走位同时完成“借镜破盾、极速逆转深负值数字门、引爆连锁电容桶”的高光操作。
   - 正向门、逆转负门、击破秘钥舱与连锁爆炸共同积攒**棱镜共鸣槽（Resonance Gauge）**，满槽自动触发 `6` 秒 V 翼超载（`1.5×` 射速 + `+1` 穿透），让优秀决策转化为肉眼可见的火力爆发。
4. **音画演出的高度统一**：
   - 自研 `Web Audio API` 13 通道程序化合成器与 `124 BPM` 赛博合成波音序器，将射击改写门数值映射为逐半音攀升的清脆音阶，在负转正瞬间奏响大三和弦琶音，在升级、连锁击杀与三关多阶段 Boss（`Warden-01`、`Hydra-02`、`Omega-Zero`）击破时呈现完整的“预备—爆发—收尾”演出，并支持一键持久化静音。
